# Nom du Projet
Catalogue de produit : il va nous servir a afficher nos produit sortant de la base de donnés, et à detailler nos produit pour plus d'information


## Technologie Utilisé
-React 18
-vite / Create React App
-TailwindCss
-Daisy UI
-axios

## Lancer le Projet
-Npm run dev
-Npm run server

## Structure du projet
src/
    composant/
        liste_produit.jsx
        detail_produit.jsx

    App.jsx
    Main.jsx
